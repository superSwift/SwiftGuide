# BRD v1（业务需求文档）- A股无图形量化系统

## 1. 背景与目标

- 背景：先建设“无图形、可扩展”的量化核心系统，后续再接入图形化 UI。
- 目标：在不依赖前端页面的前提下，完成数据同步、策略配置、回测执行、定时运行的闭环。

## 2. 范围（v1 In Scope）

1. A股日线数据同步与查询（行情基础能力）
2. 策略配置管理（JSON 配置）
3. 策略校验（schema validate）
4. 回测任务发起、状态查询、报告读取
5. 定时运行（周频/日频）

## 3. 非范围（v1 Out of Scope）

- 自动下单/实盘交易
- 图形化策略编辑器
- 高频/实时 tick 级别策略
- 复杂机器学习训练流水线

## 4. 核心用户故事

- 作为业务Owner，我希望通过自然语言描述策略并落地为结构化配置，以便持续迭代。
- 作为业务Owner，我希望提交策略后可以一键回测并查看标准化报告。
- 作为技术Owner，我希望所有能力都通过稳定 API 暴露，以便后续无缝接入 UI。

## 5. 验收标准（v1）

1. 数据：可查询指定股票的稳定日线数据（含复权口径）
2. 策略：可创建/读取/校验策略配置
3. 回测：可提交任务并获取状态与报告
4. 运行：可按计划任务自动执行并记录日志

## 6. 非功能要求

- 可追溯：记录策略版本、执行参数、数据版本
- 可复现：同一配置 + 同一数据版本，结果一致
- 可观测：任务日志、错误码、失败重试可见
- 可扩展：API versioning + schema versioning

## 7. 里程碑（首月）

- Week 1：冻结 API 合同 + 策略 schema
- Week 2：数据稳定化与质量检查
- Week 3：策略到回测闭环
- Week 4：调度与运维基线
